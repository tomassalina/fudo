# Fudo Consumers — web

Next.js (App Router, SSR) web app for **Fudo Consumers**, lower priority than
mobile, built for future SEO. See the root [`README.md`](../README.md) for
the full project pitch, stack table, and quickstart, and
[`AGENTS.md`](../AGENTS.md) for canonical conventions.

## Stack

Next.js (App Router, SSR), TypeScript, Tailwind. See `package.json` for
exact versions.

## Running

This project uses **pnpm** (see `packageManager` in `package.json`), not npm
or yarn:

```bash
cd web
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see
the result.
